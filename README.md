# ⚖️ Mizan — ميزان البيانات

> **اعرف بياناتك. حافظ على ميزانك.**
> تطبيق أندرويد أصلي لقياس استهلاك البيانات وحمايتها، بدون root، وبدون إرسال أي شيء إلى أي سيرفر.

هذا المجلد هو **المخطط الاحترافي الكامل** لمشروع Mizan. لا يحتوي على كود Gradle بعد؛
بل يحتوي على الرؤية، والهندسة، وقيود منصة أندرويد الحقيقية، وخطة مراحل وكومتات،
وبرومبت جاهز لبدء التنفيذ في جلسة عمل جديدة.

---

## لماذا Mizan؟

MacNetMeter على الماك كان أداة شريط قوائم تقيس الشبكة وتحمي الباقة. Mizan هو الشقيق
الأندرويدي: نفس الفكرة، لكن بمنصة مختلفة تماماً، وبقدرات لا يملكها الماك:

| القدرة | MacNetMeter (macOS) | Mizan (Android) |
|---|---|---|
| قياس السرعة اللحظية | `sysctl` counters | `TrafficStats` + خدمة أمامية |
| استهلاك كل تطبيق | `nettop` | `NetworkStatsManager` (صلاحية Usage Access) |
| منع تطبيق من الشبكة | قتل العملية | **جدار ناري حقيقي عبر `VpnService`** (مرحلة متقدمة) |
| شريط القوائم | NSStatusItem | إشعار دائم + Quick Settings Tile + Widget |
| ميزانية/تنبيهات | نوافذ عائمة | إشعارات عالية الأهمية لا تُكنسل إلا بالضغط |
| الحفظ | JSON/Application Support | Room + DataStore |
| اللغة | عربي/إنجليزي RTL | عربي/إنجليزي RTL |

**الاسم:** Mizan (ميزان) — لأن الوظيفة الحقيقية ليست «قياس السرعة» بل **موازنة الاستهلاك**.
أسماء بديلة كانت مطروحة: *Rasid* (راصد)، *Wazn* (وزن)، *Nabd* (نبض).

## المكدس التقني المقترح

| الطبقة | الاختيار | لماذا |
|---|---|---|
| اللغة | Kotlin 2.x | معيار أندرويد الحديث |
| الواجهة | Jetpack Compose + Material 3 | RTL وDynamic Color بسهولة |
| البناء | Gradle KTS + Version Catalog | نسخة واحدة للمكتبات |
| قاعدة البيانات | Room | استعلامات تاريخية سريعة + Flow |
| الإعدادات | DataStore (Preferences/Proto) | بديل SharedPreferences |
| الخلفية | Foreground Service + WorkManager | قياس لحظي + مزامنة دورية |
| الحقن | Hilt (KSP) | اختبارية عالية |
| الجداول | Kotlin Coroutines + Flow | تفاعل مع Room والشبكة |
| Widgets | Glance AppWidget | واجهة حديثة |
| Tile | TileService | زر في لوحة الإعدادات السريعة |
| الاختبارات | JUnit4 + Truth + Turbine + Robolectric | يشمل Compose UI tests |
| CI | GitHub Actions + Gradle | بناء وفحص تلقائي |

> المكتبات المحددة بإصداراتها في `docs/09-scaffold.md`، وتُراجَع عند أول بناء فعلي.

## المبادئ غير القابلة للتفاوض

1. **لا root، ولا APIs مخفية، ولا خداع للصلاحيات.**
2. **الخصوصية أولاً:** لا تحليلات، لا إعلانات، لا اتصال بأي خادم؛ كل البيانات محلية.
3. **الصدق في الأرقام:** إن لم نستطع قياس شيء، نقول ذلك بدل تخمينه.
4. **خطوة = كومت** مع اختبار وبناء ناجح.
5. **العربية والـ RTL مواطن أول**، لا ترجمة لاحقة.
6. **البطارية ميزة:** لا polling كل ثانية في الخلفية بلا داعٍ.
