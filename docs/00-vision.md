# 00 — الرؤية والنطاق

## الجملة الواحدة

**Mizan يخبرك أين ذهبت بياناتك، ويمنعها من الذهاب قبل أن تنفد.**

## المشكلة

1. أندرويد يعرض «استخدام البيانات» في الإعدادات، لكنه مخفي، غير عملي، ولا ينبّهك قبل التجاوز.
2. باقات الهوتسبوت والبيانات المحدودة تنفد بسبب تطبيق واحد في الخلفية (Backup، تحديث، سوشيال).
3. الحلول الموجودة إما:
   - تطبيقات إعلانات وتجسس،
   - أو تحتاج root،
   - أو VPN أجنبي يمرّر بياناتك عبر سيرفر،
   - أو مجرد واجهة استهلاك لا تمنع شيئاً.

## الحل

تطبيق محلي بالكامل يجمع ثلاث قدرات في مكان واحد:

1. **مراقبة صادقة**: سرعة لحظية + إجمالي يومي/شهري + استهلاك لكل تطبيق.
2. **موازنة**: ميزانية للجهاز ولكل تطبيق، وتنبيهات قبل النفاد، وتمييز الشبكات المقنّنة.
3. **حماية**: Data Saver يمنع تطبيقات محددة من الشبكة فعلياً عبر `VpnService` (بدون root)، لا يقتلها فقط.

## لمن؟

- **المستخدم العربي** ذو الباقة المحدودة أو الهوتسبوت: يحتاج واجهة عربية واضحة وتنبيهات لا تُفوَّت.
- **المطوّر** الذي يريد widget/tile وبيانات قابلة للتصدير.
- **صاحب الخصوصية**: لا يريد حساباً ولا سحابة ولا تحليلات.

## داخل النطاق (v1)

- قياس السرعة اللحظية (خدمة أمامية + إشعار دائم + QS Tile).
- إجمالي اليوم/الشهر مع تصفير آمن بعد إعادة التشغيل.
- استهلاك كل تطبيق عبر Usage Access.
- سجل يومي/شهري ورسوم بيانية.
- ميزانيات وتنبيهات 80%/100% (مرة لكل مستوى في كل دورة).
- تمييز مقنّن/غير مقنّن + ملف تعريف لكل شبكة (يدوي).
- Widgets (Glance) وQS Tile.
- عربي/إنجليزي RTL، TalkBack، تصدير CSV.

## مؤجَّل لما بعد v1

- `VpnService` لقياس وحظر لكل تطبيق في الزمن الحقيقي (المرحلة 6).
- Wear OS.
- مزامنة بين الأجهزة.
- قياس جودة الشبكة (Latency/Jitter) — ممكن لاحقاً عبر `ping` sockets أو HTTP HEAD محلي.

## خارج النطاق نهائياً

- أي تتبّع أو تحليلات أو إعلانات.
- أي قراءة لمحتوى الترافيك أو DNS أو أسماء المواقع.
- أي APIs مخفية أو root.
- بيع بيانات أو ربطها بحساب.

## مؤشرات نجاح

| المؤشر | الهدف |
|---|---|
| دقة إجمالي اليوم مقابل `NetworkStatsManager` | فرق ≤ 1% |
| استهلاك البطارية في وضع المراقبة | ≤ 2% لكل ساعة على شاشة مطفأة |
| زمن فتح التطبيق | < 400 ms |
| حجم APK | < 6 MB |
| اختبارات الوحدة | ≥ 80 تغطية للمنطق الحسّاس |
| crash-free | ≥ 99% |
