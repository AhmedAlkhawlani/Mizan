# 04 — تجربة المستخدم والتصميم

## خريطة الشاشات

```text
Onboarding
 ├─ 1) الترحيب
 ├─ 2) صلاحية Usage Access
 ├─ 3) صلاحية الإشعارات
 ├─ 4) يوم بداية الدورة + الميزانية
 └─ 5) تعريف الشبكة الحالية (مقنّنة؟)

Bottom Navigation
 ├─ الرئيسية (Dashboard)
 ├─ التطبيقات (Apps)
 ├─ الحماية (Saver)
 └─ السجل (History)  ← أو دمج السجل داخل الرئيسية

Settings (من الشريط العلوي)
 ├─ اللغة، الثيم، فترة القياس
 ├─ دورة الفاتورة، الميزانية
 ├─ التنبيهات والإشعار الدائم
 ├─ ملفات الشبكات
 └─ تصدير/استيراد، حول
```

## الشاشة الرئيسية

```text
┌──────────────────────────────────────┐
│  ⚖️ Mizan              [Wi‑Fi مقنّن] │
│                                      │
│        ↓ 12.4 MB/s                   │
│        ↑ 1.2 MB/s                    │
│   ──────────────────────────────     │
│   مخطط 60 ثانية                      │
│                                      │
│  أمس/اليوم: 1.24 GB من 2.00 GB       │
│  ███████████████░░░░░░  62%          │
│                                      │
│  هذا الشهر: 18.4 GB / 50 GB          │
│                                      │
│  [⏸ إيقاف مؤقت]  [🛡 الحماية]        │
└──────────────────────────────────────┘
```

- الرقم الأكبر = السرعة اللحظية.
- الشريط = ميزانية اليوم، ويتحول كهرماني 80% وأحمر 100%.
- شارة الشبكة: Wi‑Fi / خلوي / مقنّن / هوتسبوت.
- زر الحماية يفتح شاشة Saver.

## شاشة التطبيقات

- فترات: اليوم / 7 أيام / الدورة.
- صف لكل تطبيق: الأيقونة، الاسم، البايتات، شريط نسبة من الإجمالي.
- ⋯ لكل تطبيق: تعيين ميزانية، حظر في Data Saver، معلومات.
- اضغط تطبيقاً → سجل 7 أيام + تفصيل Wi‑Fi/خلوي.
- فرز: الأكثر استهلاكاً / الاسم / الميزانية الأقرب للتجاوز.

## شاشة الحماية (Saver)

- مفتاح رئيسي: «منع التطبيقات المحظورة من الشبكة».
- تحذير واضح عن طبيعة VPN (أيقونة VPN، VPN واحد فقط).
- قائمة المحظورين مع مفتاح لكل تطبيق.
- «اسمح على Wi‑Fi فقط» خيار لكل تطبيق.
- ملفات الشبكات: البيت/العمل/هوتسبوت + سلوك كل ملف.
- حالة الجدار: نشط/متوقف + عدد الحزم المحجوبة.

## الإشعار الدائم

```text
┌────────────────────────────────────────┐
│ ⚖️ Mizan                                │
│ ↓ 12.4 MB/s · ↑ 1.2 MB/s               │
│ اليوم 1.24 GB من 2.00 GB               │
│ [إيقاف مؤقت]  [فتح]                    │
└────────────────────────────────────────┘
```

- قناة عالية الأهمية، صوت عند التنبيه فقط لا عند كل تحديث (تحديث صامت بعد الأول).
- `setOngoing(true)` ليبقى، وإجراء «إيقاف مؤقت».
- تنبيهات الميزانية تُعرض كإشعار `ongoing` منفصل بإجراء «حسناً» ليختفي بالضغط فقط.

## QS Tile

- نقرة: فتح التطبيق. نقرة طويلة: شاشة الحماية.
- النص: السرعة الحالية (`↓ 12.4M`) أو «متوقف».
- تحديث كل ثانية أثناء ظهور اللوحة.

## الودجات (Glance)

| الحجم | المحتوى |
|---|---|
| 1×1 | سرعة واحدة + لون الحالة |
| 2×1 | ↓ / ↑ + إجمالي اليوم |
| 2×2 | حلقة الميزانية + أكثر تطبيق استهلاكاً |

## نظام التصميم

- **الشبكة:** 8dp، زوايا 16–24dp.
- **الخطوط:** خط النظام (Roboto) مع أرقام ثابتة العرض (`FontFeature.tnum`).
- **الألوان:**
  - `dataDown = #22D3EE` (سماوي)
  - `dataUp = #F472B6` (وردي)
  - `warn = #F59E0B` (كهرماني 80%)
  - `danger = #EF4444` (أحمر 100%)
  - `guard = #34D399` (أخضر حماية)
- **Material You:** Dynamic Color على Android 12+ مع ألوان مخصصة كبديل.
- **الوضع الليلي:** إجباري الدعم.

## RTL والعربية

- `android:supportsRtl="true"` و`layoutDirection` من اللغة.
- كل الأيقونات الاتجاهية (أسهم، chevron) تُقلب برمجياً.
- الأرقام تبقى LTR داخل النص العربي.
- لا نص مكتوب داخل الصور؛ كل النصوص موارد `strings.xml` (`values/` و`values-ar/`).

## الوصولية

- `contentDescription` لكل أيقونة وزر وصف.
- أحجام لمس ≥ 48dp.
- تباين ≥ 4.5:1.
- TalkBack: كل بطاقة إحصائية تُقرأ كوحدة واحدة (label + value).
- احترام `Settings.Global.ANIMATOR_DURATION_SCALE` لتقليل الحركة.
- لا اعتماد على اللون فقط: النسبة والنص موجودان دائماً.

## رسائل الخطأ الفارغة

- «لم نستطع قراءة استهلاك التطبيقات» + زر «منح صلاحية الوصول للاستخدام».
- «لا توجد بيانات بعد» + شرح أن أول مزامنة قد تستغرق دقائق.
