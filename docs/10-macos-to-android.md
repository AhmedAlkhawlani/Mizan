# 10 — من MacNetMeter إلى Mizan

## ما ينتقل كما هو (تقريباً)

| الفكرة | MacNetMeter | Mizan |
|---|---|---|
| وحدات عشرية | 1 KB = 1000 B | نفس القاعدة |
| تصفير يومي | منتصف الليل + partial | نفس المنطق + دورة فاتورة |
| إعادة تشغيل | مقارنة boot + offset | نفس المنطق مع `bootEpochMillis` |
| ميزانية 80/100 | مرة لكل مستوى | نفس السياسة لكل جهاز/تطبيق |
| الشذوذ | وسيط 4× + cooldown | نفس الخوارزمية |
| التصميم | سماوي/وردي/كهرماني/أحمر | نفس الهوية |
| RTL | عربي كامل | عربي كامل |
| الخصوصية | محلي بالكامل | محلي بالكامل |

## ما يتغيّر جذرياً

| MacNetMeter | Mizan | السبب |
|---|---|---|
| `sysctl NET_RT_IFLIST2` | `TrafficStats` + `NetworkStatsManager` | واجهات أندرويد مختلفة |
| `nettop` لكل تطبيق | Usage Access (تاريخي) أو VpnService (لحظي) | لا يوجد `nettop` |
| قتل التطبيق عند تجاوز الحظر | منع الشبكة عبر VpnService | القتل غير موثوق ومؤذٍ |
| NSStatusItem | إشعار دائم + QS Tile + Widget | لا شريط قوائم |
| نافذة عائمة للتنبيه | إشعار ongoing بصوت | قيود Android 14 |
| LaunchAgent | Boot Receiver + WorkManager | دورة حياة مختلفة |
| 1 ثانية دائماً | 1 ثانية أثناء الخدمة، 15 دقيقة للخلفية | البطارية |
| ملفات JSON صغيرة | Room (آلاف الصفوف) | حجم البيانات |
| Swift/AppKit | Kotlin/Compose | المنصة |

## ما لا نعيده

- **قتل التطبيقات**: على أندرويد نمنع الشبكة بدل القتل.
- **شريط قوائم**: نستبدله بإشعار دائم + Tile + Widget.
- **SSID بالموقع**: نتجنبه في v1.
- **الاعتماد على `TrafficStats.getUidRxBytes`**: غير مدعوم.

## دروس من MacNetMeter

1. **مصدر حقيقة واحد** لكل رقم؛ لا تعرض رقمين متناقضين.
2. **اليوم الجزئي** يُعلن، لا يُخفى.
3. **اختبر إعادة التشغيل ومنتصف الليل**؛ هما مصدر معظم الأخطاء.
4. **الواجهة الجميلة لا تُغني عن أرقام صحيحة**.
5. **الكومت الصغير** يجعل المراجعة ممكنة.
6. **حماية المستخدم أهم من ميزة مثيرة**: الحظر عبر VPN أأمن من القتل.
