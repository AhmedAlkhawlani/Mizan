- `NetworkStatsManager` على هذا الجهاز/الإصدار لا يعيد إلا **الدلاء المستقرة**؛ نافذة 90 ثانية

**خطة القياس:**
1. انتظر يوماً كاملاً راقبه التطبيق من 00:00 إلى 23:59 (صف مكتمل في `device_daily` و`device_hourly`).
2. استعلم `NetworkStatsManager` لنفس اليوم بتوقيت `Asia/Aden` (نافذة `[بداية اليوم, بداية اليوم التالي)`).

   إلى استعلام المنصة — لا تخلط التعريفين.
3. قارن `SUM` تطبيقات `app_daily` (UID ≥ 10000) بمجموع `querySummary` لكل UID في نفس النافذة.
4. **لا تبدأ 4.1 إن تجاوز الانحراف 1%**؛ أصلح السبب وأعد القياس على يوم آخر.
5. استخدم `am instrument` مباشرة (أو مقارنة دلاء `device_hourly` بدلاء مستقرة) — **لا** تستخدم

## مزالق لا تكتشفها الاختبارات

- **`:core:domain` يُختبر على JDK حديث ويعمل على Android API 26.** استخدم فقط ما هو متاح على API 26:
  `Instant.atZone` نعم، `LocalDate.ofInstant` **لا** (API 34) — تسبّبت مرة بانهيار الخدمة مع نجاح
  كل الاختبارات. تحقّق من أي استدعاء `java.time` جديد.
- **`NetworkStatsManager` لا يعطي «الآن»:** الدلاء تُغلق متأخرة (ساعات أحياناً). أي قياس دقة
  يحتاج يوماً مستقراً، وأي مزامنة تحتاج نافذة يومين (المنفَّذ: أمس + اليوم).
- **استبعاد UID غير التطبيقية:** `querySummary` يعيد كل UID؛ بدون `uid >= Process.FIRST_APPLICATION_UID`
  (10000) يظهر «Shell» بغيغابايتات من ترافيك `adb`. الشرط موجود في DAO — لا تنزعه.
- **`connectedDebugAndroidTest` يزيل التطبيق بعد التشغيل** ويمسح `mizan.db` وحالة `appops`.
  للقياس استخدم `assembleDebugAndroidTest` + `adb install` + `am instrument -w` يدوياً.
- **الإصدارات مثبَّتة لسبب:** Compose BOM `2025.10.01` وNavigation `2.9.8`، لأن خط 2026 يطلب
  `compileSdk 37` وAGP 8.13.2 يقف عند 36. لا ترفعها قبل التأكد من توافق `compileSdk`.
- **أي `startForeground`** يجب أن يمرّ عبر `ServiceCompat` وأن يمرّر النوع فقط على API 34+.
- **`git push` يفشل** (`could not read Username`) — لا بيانات اعتماد. لا تفترض أن الكومتات مرفوعة.
- **قاعدة البيانات بوضع WAL**: سحب `mizan.db` وحده لا يعطي آخر البيانات؛ اسحب `-wal` و`-shm` معه،
  أو أوقف العملية قبل السحب حتى تكون الملفات ساكنة.
- **لا تلتزم `.idea/*` ولا `LICENSE`/`PROMPT.md`** الموجودان مُجهَّزين في الفهرس من قبل الجلسة الأولى.
  استخدم `git add <الملفات الجديدة>` ثم `git commit --only -- <مسارات>`.
- **لوحة التصميم** في `design/concept-board.png` هي المرجع البصري (سرعات سماوية/وردية، شريط ميزانية،
  حلقة ميزانية، تنبيه كهرماني 80%). الفجوة الحالية بينها وبين المنفَّذ موثّقة في
  `docs/12-progress.md` §11 — المتبقي فيها هو شريط الميزانية والحلقة (المرحلة 4) وشاشة الحماية (6)
  والدجت (5).
