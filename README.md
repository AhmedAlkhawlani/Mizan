# ⚖️ Mizan — ميزان البيانات

> **اعرف بياناتك. حافظ على ميزانك.**
> عدّاد بيانات أندرويدي أصلي: يقيس، يسجّل، ينبّه، ويحجب — محلياً بالكامل، بلا root، وبلا صلاحية إنترنت.

ميزان تطبيق Kotlin/Compose يقيس استهلاك البيانات على الجهاز، يفصّله لكل تطبيق، ويمنع تطبيقات
مختارة من الوصول للشبكة عبر `VpnService` محلي. **لا يملك صلاحية `INTERNET`** — أي أنه لا يستطيع
الاتصال بأي خادم حتى لو تغيّر الكود لاحقاً بغير قصد.

---

## الميزات

| الميزة | التفصيل |
|---|---|
| **سرعة لحظية** | تنزيل/رفع من عدّادات النظام عبر خدمة أمامية، مع إشعار دائم وبلاطة إعدادات سريعة |
| **سرعة في شريط الحالة** | رقم السرعة يُرسم داخل أيقونة الإشعار بجانب الساعة (تنزيل/رفع/ثابت) |
| **سجل الاستهلاك** | إجمالي اليوم، 7 أيام، 24 ساعة، وانقسام خلوي/Wi‑Fi |
| **استهلاك التطبيقات** | لكل تطبيق: اليوم، 7 أيام، أو دورة الفاتورة، مع تفاصيل 7 أيام |
| **الميزانيات** | يومية وشهرية للجهاز، ولكل تطبيق؛ تنبيه عند 80% وعند التجاوز يبقى حتى يُؤكَّد |
| **دورة الفاتورة** | اختر يوم البداية (1–28) فتتبعه الميزانية الشهرية والسجل |
| **جدار الحماية** | حجب تطبيقات مختارة من الشبكة بلا root، مع عدّاد محاولات محجوبة واستثناء Wi‑Fi غير المقنّن |
| **الودجات** | ودجة سرعة (2×1) وودجة ميزانية (2×2) بإعدادات لكل منهما |
| **اختصارات** | التطبيقات، السجل، الميزانية، وإيقاف المراقبة |
| **تصدير** | CSV بالساعة عبر منتقي النظام، حيث تختار أنت |
| **إعداد أولي** | شاشة واحدة تشرح الخصوصية وتطلب الصلاحيات الاختيارية |
| **عربية أولاً** | RTL كامل، وكل نص في `values/` و`values-en/` |

## الخصوصية

- لا حساب، لا تحليلات، لا إعلانات، لا تتبّع.
- بلا صلاحية `INTERNET`، وبلا نسخ احتياطي سحابي (`allowBackup="false"`).
- كل القياسات في Room/DataStore داخل التطبيق.
- جدار الحماية نفق محلي للحجب فقط: لا يفكّ تشفيراً ولا يقرأ محتوى الحزم.

**السياسة الكاملة:** [docs/15-privacy.md](docs/15-privacy.md)

## التثبيت

| القناة | الحالة |
|---|---|
| GitHub Releases | ✅ APK موقّع عند الإصدار |
| F‑Droid | ✅ بيانات المتجر في `fastlane/metadata/android/` والبناء من المصدر |
| Google Play | ⚠️ ممكن، بشرط تبرير الصلاحيات وسياسة خصوصية منشورة |

المتطلبات: Android 8.0 (API 26) أو أحدث. لا تحدّث بين نسخة GitHub وF‑Droid وdebug معاً — لكل منها
توقيع مختلف، والنظام يرفض التثبيت فوق توقيع آخر.

## البناء

```bash
# بوابة الجودة الكاملة (تُشغَّل قبل كل كومت)
./gradlew testDebugUnitTest test lintDebug assembleDebug

# نسخة الإصدار: تحتاج keystore.properties أو متغيرات MIZAN_RELEASE_*
./gradlew assembleRelease
```

للإصدار الموقّع انسخ [`keystore.properties.example`](keystore.properties.example) إلى
`keystore.properties` (مستبعد من git) واملأ القيم. عند غيابها يُبنى الإصدار **غير موقّع**،
وهو المسار الذي تستخدمه F‑Droid كي توقّع بنفسها.

| التقنية | الإصدار |
|---|---|
| Kotlin / KSP | 2.2.21 |
| Gradle / AGP | 8.13 / 8.13.2 |
| Compose BOM | 2025.10.01 |
| Room / DataStore | 2.7.2 / 1.1.7 |
| WorkManager / Glance | 2.10.5 / 1.2.0 |
| minSdk / targetSdk | 26 / 36 |

الوحدات: `:app` · `:core:domain` · `:core:data` · `:core:platform` · `:core:designsystem`.

## الاختبارات

- **328 اختبار وحدة** على JVM: منطق الفترات والدورة والميزانيات، محرّك التنبيه، كاشف الشذوذ،
  تنسيق البايتات والـbidi، ومخططات Room وهجراتها.
- **lint** بلا أخطاء (30 تحذيراً غير حاجز).
- **التحقق على جهاز حقيقي** (Samsung SM‑N976V، Android 12): دقة القياس ≤1% مقابل
  `NetworkStatsManager` على دلو مغلق، والحجب الفعلي لواجهة الحماية، والنصوص العربية RTL. ما لم
  يُشاهد بعد (الودجات على الشاشة، الاختصارات من المشغّل، نسخة R8 وقت التشغيل) مسرود صراحةً في
  [docs/12-progress.md](docs/12-progress.md) §9.

## المبادئ غير القابلة للتفاوض

1. لا root، ولا APIs مخفية، ولا خداع للصلاحيات.
2. الخصوصية أولاً: بلا خادم، بلا تحليلات، بلا إعلانات.
3. الصدق في الأرقام: ما لا يمكن قياسه يُقال إنه غير معروف، لا يُخمَّن.
4. خطوة = كومت، مع بوابة اختبار وبناء ناجحة.
5. العربية وRTL مواطن أول، لا ترجمة لاحقة.
6. البطارية ميزة: لا استعلامات في الخلفية بلا داعٍ.
